# Three-In-One Game

Created by Sai Aik Too Aung  
Student ID: 6746027

A Unity project containing three mini-games accessible from one main menu.

## Games

### Mad Driver
Drive a vehicle along the road and avoid obstacles.

Controls:
- W / S or Up / Down arrows: Drive forward and backward
- A / D or Left / Right arrows: Turn

### Fly Like a Bird
Control a flying plane and navigate around obstacles.

Controls:
- W / S or Up / Down arrows: Tilt the plane

### I'm a Sumo and a Ball
Push enemies off the platform while staying on it.

Controls:
- WASD or arrow keys: Move

Scoring:
- Normal enemy: 5 points
- Strong enemy: 10 points
- Reach 50 points to win
- Falling off the platform ends the game

## Pause Menu

Press Escape to pause or resume.

The pause menu includes:
- Resume
- Restart
- Back to Main Menu

## How to Run

1. Download or clone this repository.
2. Open the project through Unity Hub using Unity 6.5 (6000.5.3f1).
3. Open Assets/Scenes/MainMenu.unity.
4. Click Play.
